# Results directory

The analysis script/notebook writes reproducibility outputs here. Generated result files are intentionally not required for the source repository because they can be regenerated from the public data and frozen TCGA manifest.

Expected central outputs include:

- discovery cohort and donor-level checkpoints
- genome-wide exact sign-permutation results
- frozen 43-gene signature checks
- sensitivity analyses
- TCGA expression/scoring checks
- TCGA PFI Cox and median-split results

The expected numerical checkpoints are documented in the repository root `README.md` and in the manuscript.
